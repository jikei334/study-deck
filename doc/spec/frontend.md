# frontend モジュール仕様書

## 概要

React + TypeScript + Vite によるSPA。バックエンドのREST APIと通信し、クイズ・可視化・用語検索・管理機能のUIを提供する。

---

## 技術スタック

| 技術 | 用途 |
|------|------|
| React 18 | UIフレームワーク |
| TypeScript | 型安全 |
| Vite | ビルドツール・開発サーバー |
| React Router v6 | クライアントサイドルーティング |
| Tailwind CSS | スタイリング |
| Recharts | レーダーチャート・棒グラフ |
| Axios | API通信 |

---

## 画面一覧・コンポーネント構成

### ページ一覧

| ページ名 | パス | 概要 |
|---------|------|------|
| ExamSelectPage | `/` | 試験選択（ホーム） |
| DashboardPage | `/exams/:examId` | 試験ごとのダッシュボード |
| QuizSetupPage | `/exams/:examId/quiz` | クイズのモード・カテゴリ選択 |
| QuizSessionPage | `/quiz/sessions/:sessionId` | クイズ実行 |
| QuizResultPage | `/quiz/sessions/:sessionId/result` | クイズ結果 |
| TermsPage | `/exams/:examId/terms` | 用語一覧・検索 |
| AdminPage | `/admin` | 管理画面（タブ切り替え） |

---

### ExamSelectPage（ホーム）

- 登録済み試験をカード一覧で表示
- カード: 試験名・説明・累計クイズ回数・全体正答率を表示
- カードクリックでDashboardPageへ遷移
- 「試験を追加」ボタンでAdminPageへリンク

---

### DashboardPage

- ヘッダー: 試験名・「クイズを始める」「用語を検索」ボタン
- **レーダーチャート**: カテゴリ別正答率（Recharts RadarChart）
- **棒グラフ**: カテゴリ別正答率（Recharts BarChart）、正答率の低い順にソート
- **セッション履歴テーブル**: 日時・モード・スコア（正解数/問題数）・正答率を一覧表示（最新10件）

---

### QuizSetupPage

- 選択項目:
  - モード: カテゴリ別 / 全問ランダム / 苦手重点
  - カテゴリ（カテゴリ別モード選択時のみ表示）
  - 出題数（10 / 20 / 全問）
- 「クイズ開始」ボタンでPOST `/api/quiz/sessions` を呼び出し、QuizSessionPageへ遷移

---

### QuizSessionPage

- 上部: 進捗バー（現在の問題番号 / 総問題数）・正答数
- 問題文を大きく表示
- 4つの選択肢ボタン
- 選択後:
  - 正解の選択肢を緑、不正解を赤でハイライト
  - 選んだ選択肢の説明文（choices.explanation）を表示
  - 正解の選択肢の説明文を表示
  - 「次の問題へ」ボタン
- 全問終了後、「結果を見る」ボタンでQuizResultPageへ遷移

---

### QuizResultPage

- スコアサマリー: 正解数 / 総問題数・正答率・所要時間
- カテゴリ別正答率の棒グラフ
- 問題ごとの正誤一覧テーブル（問題文・選択した答え・正解・正否）
- 「もう一度」「ダッシュボードへ」ボタン

---

### TermsPage

- 検索ボックス（入力と同時にリアルタイム検索）
- カテゴリフィルタードロップダウン
- 検索結果: 用語名・カテゴリ・説明文をカード形式で表示
- デフォルトは全用語表示（アルファベット順）

---

### AdminPage

- タブ切り替えで以下を管理:
  - **試験タブ**: 試験一覧テーブル・追加フォーム・編集・削除
  - **カテゴリタブ**: 試験で絞り込み → カテゴリ一覧・追加・編集・削除
  - **問題タブ**: カテゴリで絞り込み → 問題一覧・追加フォーム・編集・削除
    - 問題追加フォーム: 問題文・選択肢4つ（各テキスト＋説明文＋正解フラグ）・解説
  - **用語タブ**: カテゴリで絞り込み → 用語一覧・追加・編集・削除

---

## API通信インターフェース

バックエンドのAPIは `http://localhost:3000` を向く（環境変数 `VITE_API_BASE_URL` で設定可能）。

---

## エラーケース

| ケース | 対応 |
|--------|------|
| API通信失敗 | トースト通知でエラーメッセージ表示 |
| 問題が0件のカテゴリでクイズ開始 | クイズ開始前にバリデーションして警告 |
| 存在しないsessionIdへのアクセス | 404表示してホームへ誘導 |
| 存在しないexamIdへのアクセス | 404表示してホームへ誘導 |

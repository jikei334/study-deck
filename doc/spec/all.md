# study-deck 仕様書

## 概要

資格試験学習支援Webアプリケーション。クイズによる知識確認、苦手分野の可視化、用語検索機能を提供する。
初期データとしてAWS Cloud Practitioner試験の問題・用語を収録するが、他の試験にも対応できる汎用設計とする。

---

## ターゲットユーザー

資格試験（特にクラウド・IT系）の学習者

---

## 機能要件

### 1. 試験選択（トップページ）

- アプリ起動時に登録済みの試験一覧を表示
- 試験カードをクリックするとその試験のダッシュボードへ遷移
- 試験追加ボタンから管理画面へショートカット

### 2. クイズ機能

- **出題形式**: 4択選択式
- **出題モード**:
  - カテゴリ別モード: 特定カテゴリの問題のみ出題
  - 全問ランダムモード: 全カテゴリからランダムに出題
  - 苦手重点モード: 正答率が低い問題を優先して出題
- **クイズフロー**:
  1. 問題文と4つの選択肢を表示
  2. 選択後、即座に正解/不正解を表示
  3. 選んだ選択肢と正解の選択肢それぞれに対して「なぜ正解/不正解か」の説明を表示
  4. 次の問題へ進む
- **セッション管理**:
  - クイズ開始時にセッションを作成
  - 各回答（問題ID、選択肢、正否、回答時刻）を記録
  - セッション終了時にスコアを集計・表示

### 3. 苦手分野の可視化（ダッシュボード）

- 試験ごとのダッシュボード画面:
  - レーダーチャート: カテゴリ別正答率を蜘蛛の巣状に表示
  - 棒グラフ: カテゴリ別正答率と問題数を表示
- **表示データ**:
  - 全期間の累計正答率（カテゴリ別）
  - 直近N回のセッション履歴一覧（日時、スコア）
- ダッシュボードからクイズ開始・用語検索へのナビゲーション

### 4. 用語検索

- **検索対象**: 用語名・説明文の全文検索（SQLite FTS）
- **検索結果表示**:
  - 用語名
  - カテゴリ
  - 説明文（Notionメモの内容）
- **絞り込み**: カテゴリでフィルタ可能（試験は選択済みのため不要）

### 5. 問題管理（管理画面）

- **試験（Exam）管理**: 試験の追加・編集・削除
- **カテゴリ管理**: カテゴリの追加・編集・削除（試験に紐づく）
- **問題管理**:
  - 問題の追加・編集・削除
  - 問題文・4つの選択肢（各選択肢に「なぜ正解/不正解か」の説明付き）・正解・解説を入力
  - カテゴリへの紐付け
- **用語管理**: 用語の追加・編集・削除

## 初期収録データ（AWS Cloud Practitioner）

試験名: AWS Cloud Practitioner

カテゴリ（8つ）:
1. ストレージ
2. データベース
3. AI・ML・データ分析
4. セキュリティ
5. モニタリング・コンプライアンス・ガバナンス
6. 料金体系・サポート
7. クラウドへの移行
8. Well-Architectedソリューション

初期問題数: 約80問
初期用語数: 約60語

## 非機能要件

- **動作環境**: Podman（Ubuntu 26.04ベース）でのコンテナ実行
- **レスポンシブ**: PCブラウザを主体とし、タブレットでも閲覧可能
- **言語**: UI・コメントは日本語
- **アクセス制御**: 認証なし（ローカル利用前提）

## 画面一覧

| 画面名 | パス | 概要 |
|--------|------|------|
| 試験選択（ホーム） | `/` | 登録済み試験の一覧を表示し、試験を選ぶ |
| ダッシュボード | `/exams/:examId` | 選択した試験の可視化・ナビゲーション |
| クイズ選択 | `/exams/:examId/quiz` | モード・カテゴリを選択してクイズ開始 |
| クイズ実行 | `/quiz/sessions/:id` | 問題出題・回答・解説表示 |
| クイズ結果 | `/quiz/sessions/:id/result` | セッションのスコアと正誤一覧 |
| 用語検索 | `/exams/:examId/terms` | 用語一覧・検索 |
| 管理画面 | `/admin` | 試験・カテゴリ・問題・用語の管理 |

## データモデル概要

```
Exam（試験）
  └── Category（カテゴリ）
        ├── Question（問題）
        │     └── Choice（選択肢）×4  ← 各選択肢に説明文あり
        └── Term（用語）

QuizSession（クイズセッション）
  └── QuizAnswer（回答）
```

| テーブル | 主なカラム |
|---------|-----------|
| exams | id, name, description |
| categories | id, exam_id, name |
| questions | id, category_id, text, explanation |
| choices | id, question_id, text, is_correct, **explanation**（なぜ正解/不正解かの説明） |
| terms | id, category_id, name, description |
| quiz_sessions | id, exam_id, mode, started_at, completed_at |
| quiz_answers | id, session_id, question_id, selected_choice_id, is_correct, answered_at |
